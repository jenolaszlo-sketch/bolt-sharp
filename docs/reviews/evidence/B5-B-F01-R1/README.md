## Confidentiality

The probe and suites use synthetic loopback test credentials only. The probe output redacts the
LOGON payload at the raw-chunk level; no credential value appears in any captured output or
document. TLS material is generated in memory by the driver suite and never written to disk. No
real secrets, private keys or PFX files are present in this directory.

## Hash convention

`manifest.json` records the SHA-256 of each evidence file's exact working-tree bytes (the
repository's canonical checkout form; this directory carries `* -text`). The historical manifest
verifier compares raw bytes the same way, which is why all historical manifests remain valid
without rewriting. The authorized F01-R1 production change supersedes
`src/BoltSharp/Transport/BoltTcpConnection.cs`; no historical manifest hashes that file, so the
518/518 verification is unaffected and no historical artifact was rewritten.
