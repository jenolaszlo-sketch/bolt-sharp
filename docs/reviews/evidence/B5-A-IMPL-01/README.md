## Reproduction

From the repository root:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File docs/reviews/evidence/B5-A-IMPL-01/Run-B5AImpl.ps1
```

The script is deterministic apart from ephemeral ports and generated certificate material.
The network probe is generated by the script into a scratch directory outside the repository
(the probe is test-only tooling, not repository source).

## Confidentiality

All credentials in the traces are synthetic sentinels (`probe-user` / `probe-secret`). The TLS
certificate is generated in memory by the probe and never written to disk in key form. No
production secret, private key or certificate password appears anywhere in this directory.

## Hash convention

`manifest.json` records the SHA-256 of each evidence file's exact working-tree bytes (the
repository's canonical checkout form). The historical manifest verifier compares raw bytes the
same way, which is why all historical manifests remain valid without rewriting.
